# AI 模型榜单设计

状态：已实施；当前数据来源与口径以 `sources.md` 为准（2026-10-28 重构）。

## 目标与已确认范围

在现有 AI 模块的侧栏新增「模型榜单」，集中浏览前沿模型在不同领域的来源排名。仅展示模型，不纳入 Cursor、Claude Code 等工具产品，不自行运行评测，不合成跨来源总分。

领域顺序：编程、图片、前端、财务、综合。图片细分生成、编辑、理解；删除 3D。

用户无需注册、配置 API Key 或付费。以免费、可匿名获取且允许复用的数据为接入范围；不依赖 Hatch 已配置的 LLM，也不通过 LLM 生成排名或猜测发布日期。

## 方案比较与选择

- A：领域优先。选择领域后，并排展示多个来源，可筛选单个来源。便于比较同一领域的模型表现。用户已选择此方案。
- B：来源优先。每个来源独立切换领域。便于浏览某家评测，但横向比较操作更多，未选择。

## 页面行为

沿用现有 AI 侧栏和 aiSubTab 导航，不新增顶层模块。领域切换置于榜单页顶部，来源筛选默认「全部来源」。全部来源时使用响应式多列卡片，窗口窄时纵向排列；单来源时保留该榜单。

建议默认领域为「编程」，图片默认子分类为「生成」。每张卡片先展示前 10 条，支持展开全部。这些为设计默认值，尚未单独确认。

每张榜单显示来源、具体评测名称、原站入口、同步状态及最近成功同步时间。条目显示原始排名、完整模型版本名称、原始分数和单位、发布或版本更新日期、距今天数。模型开发商在来源提供时展示。

同名模型的不同版本、推理配置不擅自合并；来源存在并列名次时保留。来源只提供分数时，只有排序规则明确才能计算名次，并标注「按来源分数排序」。不同评测口径分别展示，不暗示分数可横比。编程不以综合成绩代替；前端只接入明确面向网页或界面生成的模型评测；排除整套工具或 Agent 系统榜单。

## 日期口径

天数对应条目中具体模型版本的发布或有证据的版本更新日期，不使用系列首发、榜单更新、抓取时间替代。优先精确版本的官方公告或官方模型卡；采用来源所给日期时保留出处与日期类型。

无法可靠确认时显示「未知」。仅有月份等不完整日期时保留原精度，不计算精确天数。发布与更新均已知时，标明采用的是哪种日期，并保留原发布日期供查看；不使用厂商通用文档的修改日期作为模型更新日期。天数按用户本地日历日期计算；未来日期标为「尚未发布」。

## 数据来源与接入门槛

Arena、Artificial Analysis 是用户点名的候选来源，尚未确认可在无需注册和配置的前提下完整同步。不能承诺这两家均可自动接入。

接入前逐项验证：官方归属、可匿名访问、复用许可、领域含义、评测对象确为模型、实际数据结构、更新时间、日期覆盖和稳定性。优先官方公开 JSON/CSV、公开数据集或明确允许使用的匿名接口；公开可浏览的页面不自动视为可抓取授权。

初查：Artificial Analysis 的 Data API 文档要求 API Key；不作为本方案的直接接口。Arena 的服务条款限制自动查询与抓取，需另行确认官方授权的公开数据集及其许可、覆盖和时效。财务可调查 HELM Finance 等专项榜单；这只是候选，不代表已经验证接入。

缺少可用接口时标为「暂未接入」并保留链接；没有对应专项榜单时标为「无对应榜单」。不填入示例名次或将陈旧静态数据描述为实时排名。

实施第一阶段必须先完成匿名数据可行性验证和来源覆盖表，至少有一个真实可同步的模型榜单才能交付功能。默认编程领域应有真实数据；如不能达到，或大部分领域只能提供链接，应先向用户说明并重新确认范围，不以空页面当作完成。

## 刷新与缓存

进入页面时立即展示本地缓存；距成功同步超过 24 小时则刷新。提供手动刷新。仅在 Hatch 运行且进入页面时触发，不新增后台自动化或退出应用后的任务。

缓存按具体榜单维护，独立记录成功时间与最近尝试时间；失败不更新成功时间、不覆盖旧数据。各来源独立失败，保留可用来源。页面显示首次加载、正常、刷新中、旧缓存、获取失败和未接入状态。为请求设置超时、大小限制和短时重试退避，避免失败后每次切换都重复请求；同一榜单并发刷新合并。

## 工程落点（设计建议）

Go 新增独立 ai/leaderboard 包承载来源适配、格式归一化、日期元数据及本地缓存；src/app 的 ai_ 前缀文件只提供薄绑定。缓存使用 Hatch 数据目录下独立 JSON 文件并原子写入，不混入用户配置；不引入常驻服务或数据库。来源定义随应用分发，首版不提供用户配置或自建共享服务器。

前端沿用 Alpine、Pico 和现有主题，使用独立命名类；接入 aiGo 路由分发及页面加载。具体绑定命名、数据结构和缓存文件名留给实施计划确定。实施前读取 hatch-frontend 技能；稳定行为变化后同步最小范围的项目参考文档。

## 验收

- AI 侧栏可进入榜单，五个领域与图片三个子类顺序正确。
- 默认按领域展示多个可用来源，可切换单个来源；窗口窄时内容仍可读。
- 真实获取的数据保留评测来源、原始排名与分数，模型版本和日期出处可追溯。
- 缺失日期不编造，缺失榜单和未接入状态清楚可见。
- 无账号、无 Key、无 LLM 配置时可加载已验证的数据源。
- 缓存新鲜时不自动重复获取；过期或手动刷新时更新；单来源失败仍显示其旧数据和其他来源。
- 验证相关 Go 数据处理与缓存行为，执行前端构建及绑定变动要求的 src/ 下 go test ./...，并检查实际页面和匿名网络路径。
