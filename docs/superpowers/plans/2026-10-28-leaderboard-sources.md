- [x] 接入 EvalPlus HumanEval+ / MBPP+ 官方 Apache-2.0 results.json，分开评分，不计算平均。标注公开成绩覆盖模型较旧。

- [x] 调查图片来源 GenEval 官方 MIT 论文结果；如纳入则明确历史学术快照，排除 CLIP retrieval 非生成模型基线。
- [x] 新来源无原始 rank 时按明确分数降序生成竞赛排名（同分同名次），显示“按来源分数排序”。原始 Arena rank 不变。
- [x] 测试错误/缺字段/空数据/NaN/同分/CSV 引号换行/压缩包限制/未知模型日期及独立失败；真实匿名网络验收。

边界：不将 SWE-bench/Terminal-Bench 等 Agent 系统成绩混入模型榜；不抓取受限页面。BigCodeBench 数据卡缺少明确成绩复用许可，LiveBench 当前公开路径已变，暂不接入。HELM 仅在官方数据和授权口径确认后纳入。不新增后台任务、用户配置或第三方运行时。
